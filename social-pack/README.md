# Six-image case-study pack

Use `carousel/01-cover.png` through `06-next-steps.png` in that order. All six final images share the same 1122 × 1402 portrait canvas. They are AI-assisted presentation artwork with iPhone mockups based on the actual browser captures included in `screens/`.

- `CAPTIONS.md`: X post/thread, Instagram caption, Facebook post and posting notes.
- `CASE_STUDY_POST.md`: longer build story with bugs, decisions, tests and next steps.
- `ALT_TEXT.md`: per-image accessibility descriptions.
- `PROMPTS.json`: prompt set, input roles and generation method.
- `screens/`: raw game captures and the reported error used as evidence/source material.

The rendered phone illustrations can contain small type/device-detail differences; the raw captures are the source of truth. The game screens are genuine; the hardware frames are mockups. The temporary room code in slide 5 is not a live invitation. Historical squads/managers and simulated scores are labelled in the app. No content has been published to social accounts.

Before public posting, deploy/test a real URL if you want to add one, review captions in your own voice and keep the stated test/device limitations. These materials intentionally contain no invented launch, install, revenue or growth metrics.
